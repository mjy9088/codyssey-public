# Troubleshooting Handoff

This file is an explicitly required submission-record location, not a completed team log.
Record actual participants and links after the real exercises. Keeping run logs in Git is normally
poor practice; this exception does not justify fabricated or unnecessary transcripts.

The rerunnable disposable lab demonstrates:

| Operation | Intended use | Invariant checked |
| --- | --- | --- |
| amend | Clarify an unpublished commit | Tree content unchanged |
| soft reset | Rework a local draft | Staged changes remain |
| revert | Undo a published change append-only | Published commit remains an ancestor |
| stash/pop | Pause unfinished work | Clean transition and restored draft |

For each real team exercise, explain the initial state, command choice, actual outcome, affected
collaborators, verification and safer alternatives. Do not rewrite shared history without agreement.
