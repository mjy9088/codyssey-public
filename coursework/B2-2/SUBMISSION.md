# Submission Handoff

The code and local practice lab are candidate material. Human GitHub collaboration is not completed
by this automated workspace. Before hand-in, record the actual repository and participants, each
person's issue/merged-PR/review links, review responses and contribution commits. Link the genuine
conflict and troubleshooting records and the required Git history capture.

Do not submit placeholder URLs or claim the synthetic actors in `verify/check.sh` are people.
This index and the minimum required real evidence are explicit submission exceptions; ordinary run
logs should remain in ignored artifact storage rather than Git.
